SIMRS OTTEN 32

Sistem manajemen rumah sakit terintegrasi untuk rumah sakit medium — menyatukan pendaftaran pasien, rekam medis elektronik, farmasi, laboratorium, radiologi, dan billing dalam satu arsitektur berlapis berbasis Spring Boot.

01 — OVERVIEW

Dibangun untuk operasional 1000+ pasien/hari

SIMRS OTTEN 32 dirancang sebagai sistem modular yang mendigitalkan proses inti rumah sakit: dari pasien masuk di UGD, konsultasi poliklinik, hingga penagihan akhir. Setiap unit — gawat darurat, rawat jalan, rawat inap, radiologi, laboratorium, dan apotek — punya alur data yang saling terhubung lewat lapisan API yang sama.

Visi sistem ini adalah efisiensi operasional lewat digitalisasi penuh manajemen pasien, integrasi data medis-administratif, serta keamanan dan privasi data yang ketat.

03 — MODUL

Enam modul bisnis inti

Setiap modul memiliki entity database, service layer, dan endpoint REST sendiri, disusun dalam paket terpisah di dalam simrs-core.

Manajemen Pasien

8 endpoint
  • Registrasi & verifikasi data pasien baru
  • Penomoran rekam medis otomatis
  • Pencarian & filter pasien, verifikasi BPJS/asuransi
Entity: Patient, PatientContact, PatientInsurance, PatientMedicalHistory

Rekam Medis Elektronik (EMR)

multi-user
  • Riwayat kunjungan, diagnosis, dan resep digital
  • Catatan klinis & ringkasan pemulangan pasien
  • Akses berjenjang untuk dokter, perawat, dan admin
Entity: MedicalRecord, Diagnosis, ClinicalNotes, VitalSigns

Farmasi

stok
  • Inventori & pembelian obat
  • Pemantauan kedaluwarsa & stok menipis
  • Dispensing berbasis resep digital
Entity: Medicine, MedicineStock, Prescription

Laboratorium

3 status
  • Permintaan & pelacakan jenis tes
  • Status PENDING → PROCESSING → COMPLETED
  • Riwayat hasil lab per pasien
Entity: LabRequest, LabSample, LabResult

Radiologi

imaging
  • Penjadwalan & permintaan pemeriksaan
  • Penyimpanan path gambar & temuan
  • Verifikasi radiolog, siap integrasi PACS
Entity: RadiologyRequest, RadiologyResult

Billing

invoice
  • Pembuatan invoice & pelacakan pembayaran
  • Rekonsiliasi keuangan & laporan revenue
  • Penomoran invoice otomatis
Entity: Invoice, Payment, InsuranceClaim

05 — ARSITEKTUR

Arsitektur berlapis

Empat lapisan yang jelas memisahkan tampilan, logika bisnis, dan data — memudahkan setiap modul berkembang tanpa saling mengunci.

Presentation Layer
Web UI — belum dibangun, direncanakan React/Angular
↕
API Layer (REST)
Spring Boot Controllers — modul simrs-api
↕
Business Logic Layer
Services & business rules — modul simrs-core
↕
Data Access Layer (JPA)
Repository & entity — Hibernate/JPA
↕
Database Layer
MySQL 8.0, migrasi via Flyway

08 — MENJALANKAN

Quick start

# clone & masuk direktori
git clone https://github.com/fahmisetiawan63-sudo/SIMRS-Hospital-Management.git
cd SIMRS-Hospital-Management

# build seluruh modul
mvn clean install

# jalankan API server
cd simrs-api
mvn spring-boot:run

# akses
http://localhost:8080/api/v1
http://localhost:8080/swagger-ui.html
